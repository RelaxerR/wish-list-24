# Правила ежедневного ревью трек-листа

Этот файл читает ежедневная задача Claude перед тем, как обновить `review.json`.
Правь его, если хочешь поменять логику разбора: следующий прогон подхватит изменения.

## Формат сета

- Open format, опорные жанры: **tech house**, **UK garage**, **dubstep**. Всё остальное — треки, чтобы попеть (блок `sing`).
- Длина сета ≈ 2,5–3 часа (40–50 треков), 4 волны.
- Сет идёт волнами: `tech` → 2 трека `sing` → разгон в `ukg` → разрешение в `dubstep` → 2 трека `sing` → снова `tech` → …
- BPM тоже волнами: внутри волны темп растёт к dubstep (≈140), затем сбрасывается на `sing`/`tech` (≈120–130).
- Внутри блока по возможности ставить соседние треки гармонично (Camelot: тот же номер, ±1, или смена A↔B
  с тем же номером). Если гармоничного перехода нет — так и написать в `note` (кат, эффект, перкуссия).
- **Чередовать гостей**: не больше 2 треков подряд от одного человека.
- Трек, который заказали несколько человек, — приоритетнее.
- Треки со «Статус» = «сыграно» в сет не включать (они уже отыграны).

## Источник треков: папка Славы

- `crate.json` — снимок скачанных треков из `/Volumes/SamsungT7/Music/DJ` (теги ID3: BPM, тональность, жанр, блок).
  Это основной материал сета: **треки из папки в приоритете** (`"inCrate": true`).
- Если ночной прогон может достучаться до компьютера Славы (инструменты remote-devices доступны), сначала
  пересканировать папку и обновить `crate.json`; если нет — работать с последним снимком.
- Гостевую заявку сначала искать в `crate.json` (по исполнителю и названию, ремиксы/блэнды тоже считаются).
  Нашлась — брать BPM/тональность из тегов и ставить `inCrate: true`, `pack`.
- Чего нет в папке — искать на **https://muzvizor.com** (жанры: `/genres/tech`, `/genres/uk`, `/genres/dubstep`,
  `/genres/bass`, `/genres/pop`…) и **https://promodj.com** (`/music/{жанр}`, страницы треков). Слава качает оттуда,
  поэтому в `download` класть ссылку на страницу трека или жанра, где он есть.

## Фильтрация (`rejected`)

Отсеивать с короткой понятной причиной:
- тестовые/мусорные строки, не треки;
- трек не находится в открытых источниках;
- явный дубль (тогда объединить заказавших в `from` у одного трека, а не отсеивать);
- совсем не ложится в формат вечеринки (медленные баллады, неуместное по смыслу) — обязательно предложить
  альтернативу в `suggestions` с полем `instead`.

## Исследование треков

- Для каждого нового трека найти BPM, тональность (+ Camelot), жанр. Сначала `crate.json`, затем muzvizor.com / promodj.com, затем mixgraph.io, tunebat.com,
  songbpm.com, beatport.com и т.п. Ссылки положить в `sources`.
- Если источники расходятся — указать оба варианта в `note`. Не выдумывать: неизвестное = `null`.
- Уже исследованные треки хранить в `library` (ключ — `исполнитель|название` в нижнем регистре), чтобы
  не искать заново каждый день.

## Предложения

- `set` может содержать мои треки-заглушки (`"suggested": true`), если без них волна не собирается.
  Чем больше заявок гостей, тем меньше заглушек — гостевые треки в приоритете.
- `suggestions` — до 6 треков: альтернативы отсеянным, дополнения в слабые блоки, мостики между блоками.

## Схема `review.json`

```json
{
  "version": 1,
  "updatedAt": "ISO-8601 с часовым поясом, например 2026-10-13T00:05:00+04:00",
  "responsesSeen": 0,
  "summary": "1–2 коротких предложения для ГОСТЕЙ (страница публичная): без слов «папка», «скачать», «Claude», без диджейской кухни",
  "set": [{ "artist": "", "title": "", "from": ["имя"], "suggested": false,
            "wave": 1, "block": "tech|sing|ukg|dubstep|other", "genre": "", "bpm": 0, "key": "", "camelot": "",
            "note": "", "sources": ["url"],
            "inCrate": true, "pack": "папка в DJ", "download": "url для скачивания, если нет в папке" }],
  "rejected": [{ "artist": "", "title": "", "from": ["имя"], "reason": "" }],
  "suggestions": [{ "artist": "", "title": "", "block": "", "bpm": 0, "key": "", "camelot": "",
                    "why": "", "instead": "Исполнитель — Название", "download": "url" }],
  "library": { "исполнитель|название": { "bpm": 0, "key": "", "camelot": "", "genre": "", "sources": [] } }
}
```

Страница показывает только порядок, исполнителя, название, кто заказал, BPM и Camelot. `note`, `inCrate`, `download`
и `suggestions` — служебные, для диджея (видны в JSON и в отчёте задачи), держать их короткими.

`index.html` не трогать — страница сама рендерит `review.json`.
